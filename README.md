A single funny line for make.fun's "The Battery's Last Text to Its Charger" bounty ($2 in USDC). A jealous phone battery texts its charger: it waited all day while the charger topped up the tablet, the watch and the earbuds, and only at 1% is it suddenly the charger's whole world — so it threatens to tell the fridge everything.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
